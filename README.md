Automated provisioning, configuration, and dynamic content deployment for Nginx web servers across AWS EC2 instances using **Ansible** and **Jinja2** templates.

## 📌 Project Overview

This project automates the setup of a scalable web server environment on AWS EC2 instances. Managed entirely through Ansible from a central control node (`Main`), it enforces state idempotency, dynamic server profiling via Jinja2 templating, and automated service lifecycle management.
